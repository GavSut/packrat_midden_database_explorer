Methods & sources

What you are exploring

Strickland and colleagues’ USGS North American Packrat Midden Database, Version 5.0 (2022). The complete upload contains 3,331 samples, 3,843 age rows, 1,815 taxon definitions and 29,393 taxon–sample records.

The unit of selection is SAMCODE, not a unique site. Multiple samples may share a name or coordinates. Points group exact coordinate pairs; every sample is retained in the table and export.

Source release & citation ↗

Taxa and non-records

Select explicit VARNUMs. Search includes original names, accepted names, common names and families. Synonyms are available in the raw tables, but are not merged automatically: some include uncertain identifications or hybrids.

0 = explicit absence; 1 = rare; 2 = present; 9 = possible contaminant. Unreported taxa are not biological absences. Gray context points have no records for any selected taxon. They use the same non-taxon filters as the foreground.

Filtering by positive evidence uses codes 1 and 2. Inspect original notes before scientific analysis; a positive code does not guarantee unambiguous identification.

Age selection and uncertainty

Preferred ages are selected in order: pooled X1-PA / X1-PA(FST), X, X?, X2, then uncertain candidates. Selection happens before numeric availability is checked. A missing calibrated preferred age is never silently replaced with a different date.

The cautious option includes failed pooled tests, suspect dates, ambiguous multiple recommendations and nonstandard candidates. Infinite dates remain in the source records but are not treated as exact ages.

Calendar ages use CALIB 7.0.4 / IntCal13. Radiocarbon and calendar years are separate scales, both before 1950. Overlap uses the absolute lower–upper calibrated envelope, which may bridge gaps between probability intervals. This is exploratory interval matching, not chronological uncertainty propagation.

Colors, labels and the histogram use the youngest matching preferred point age. With the age filter off, they use available preferred ages under the selected quality setting. Colors rescale to the selection. Gray means no usable point age.

Coordinates and climate

Coordinates use BEST_OR_PUB latitude/longitude. Some source locations are intentionally approximate. No missing coordinates are invented. Elevation uses BEST_ELEV(M), then ELEV(M)1. Modern climate variables describe open-area climatology near sites, not past climate.

Downloads and reproducibility

Sample CSV: one row per sample with normalized fields. Long-form CSV: original occurrence fields plus names, codes and selected sample context. Matrix: VARNUM columns; blank means unrecorded, 0 is explicit absence, and 9 remains flagged.

Analysis ZIP: normalized exports, all original related rows for selected samples (including all ages), matched ages, taxon definitions, referenced publications, full lookup/unlinked context, and a query manifest containing IDs, filter settings and source hashes.

Raw CSV exports preserve source string values and sentinels; normalized numeric exports convert blanks, n/a and 99999 to empty values. Optional spreadsheet-safe output prefixes formula-like text; leave it off for exact analysis values.

The original data files remain unchanged. The interface is static, with no telemetry or account dependency. Online basemaps are optional.

Using this repository

Open site/index.html directly, or run python3 scripts/serve.py from the repository. To publish, push this project and enable GitHub Pages with GitHub Actions. The included workflow builds, tests and deploys the explorer as the home page.

For updates, replace the original release tables under data/raw, then run python3 scripts/build_data.py. Unexpected duplicate/orphan keys stop the build.

Map library: Leaflet 1.9.4. ZIP library: JSZip 3.10.1. Bundled boundaries: Natural Earth 1:110m. Country outlines are only orientation aids.
