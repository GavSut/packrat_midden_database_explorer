This version of the Midden Database contains data for 3,331 packrat midden samples obtained from published sources (journal articles, book chapters, theses, dissertations, government and private industry reports, conference proceedings) as well as unpublished data contributed by researchers.  Compared to the previous version of the Midden Database (i.e., ver. 4), this version of the database (ver. 5.0) has been expanded to include more precise midden-sample site location data, calibrated midden-sample age data, and plant functional type (PFT) assignments for the taxa in each midden sample.  In addition, World Wildlife Fund ecoregion and major habitat type (MHT) assignments (Ricketts and others, 1999) and modern climate and bioclimate data (New and others, 2002; Davis and others, 2017) are provided for each midden-sample site location.  ----------REQUIREMENTS----------The data are stored in text files with comma-separated values (.csv), Microsoft Excel (.xslx) files, and a Microsoft Access database (.mdb) file.  Additional software may be required to open the Microsoft Excel and Microsoft Access files. ----------HOW TO CITE THESE DATA----------Strickland, L.E., Thompson, R.S., Anderson, K.H., Pelltier, R.T., Shafer, S.L., Bartlein, P.J., Schumann, R.R., and McFadden, A.K., 2022, USGS North American Packrat Midden Database, Version 5.0: U.S. Geological Survey data release, https://doi.org/10.5066/P91UOARW.----------CONTENTS----------In addition to this readme file, this data release includes a metadata file (.xml and .txt), a data dictionary file (.csv), a Microsoft Access database file (.mdb), and the Linked, Unlinked, and Lookup data tables (.xlsx and .csv) listed below.  The data contained in each table are described in the data dictionary file.  In the Microsoft Access database, .xlsx, and .csv files, not all midden samples have complete data.  Generally, cells that contain "99999" indicate that published data were not available, or data were unable to be generated.  Blank cells may also indicate that published data were not available (e.g., location data fields) or blank cells may appear in unused fields such as notes or comments, fields with flags, and secondary data fields.  The abbreviation "n/a" (not applicable) was used when it was not applicable to record data in a cell.Below are the file names and content descriptions for the 10 Linked tables, 4 Unlinked tables, and 6 Lookup tables in the midden database.  See the data dictionary file for additional details regarding the information contained in each table.LINKED DATA TABLES 1-10LINKED TABLE 1: REFERENCE(Filenames: Linked_Table_1_REFERENCE.xlsx, Linked_Table_1_REFERENCE.csv)The REFERENCE table lists the published sources that provided midden data recorded in the midden database.LINKED TABLE 2: MIDDEN SAMPLE(Filenames: Linked_Table_2_MIDDEN_SAMPLE.xlsx, Linked_Table_2_MIDDEN_SAMPLE.csv)The MIDDEN SAMPLE table contains information for 3,331 midden samples, including midden-site location and elevation data, the reference sources from which data were obtained, and a code indicating whether a taxon list is available and whether it is a complete, partial, published, or unpublished list.  We recommend using location and elevation data from the BEST_OR_PUB_LATDECDEGCON, BEST_OR_PUB_LONGDECDEGCON, and BEST_ELEV(M) fields (if there are no values in the BEST_ELEV(M) field, the ELEV(M)1 value should be used).  Users should note that for midden sites considered to be in a sensitive location (e.g., Bechan Cave, Hoopers Hollow, Sandblast Cave), we generalized the location data such that the latitude and longitude values represent only the approximate site location [see the LOCALITY_NOTES, BEST_LOCALITY_NOTES, and SOURCE(1) fields for additional details].LINKED TABLE 3: AGEC14(Filenames: Linked_Table_3_AGEC14.xlsx, Linked_Table_3_AGEC14.csv)The AGEC14 table lists midden-sample radiocarbon (carbon-14) ages and standard deviations, along with laboratory numbers assigned by the radiocarbon laboratory and information about the midden material that was dated.  We calibrated the radiocarbon ages using CALIB (rev. 7.0.4; Stuiver and Reimer, 1993) and the IntCal13.14c radiocarbon age calibration curve (CALIB was run with the 2-sigma and Cal BP options selected).  Radiocarbon ages that were <71 or >46,401 carbon-14 years, ages without reported standard deviations, and infinite ages were not calibrated.  Note that radiocarbon ages calibrated using the more recent IntCal20 curve (Reimer and others, 2020) may produce different calibrated ages for certain time periods, such as the late Pleistocene (Reimer, 2022).LINKED TABLE 4: MIDDEN TAXA(Filenames: Linked_Table_4_MIDDEN_TAXA.xlsx, Linked_Table_4_MIDDEN_TAXA.csv)The MIDDEN TAXA table lists the plant taxa identified in the midden samples.  We generally recorded the Latin botanical names as reported in the source reference containing the midden-sample plant taxon list.  In some cases, the form of a taxon's name was modified, and these changes are described in the table's NOTES field.  If the taxon's formal botanical name has changed since the publication of the source reference, the currently accepted name is listed in the CURRENTLY_ACCEPTED_VARNAME field.LINKED TABLE 5: MIDDEN TAXA PER SAMPLE(Filenames: Linked_Table_5_MIDDEN_TAXA_PER_SAMPLE.xlsx, Linked_Table_5_MIDDEN_TAXA_PER_SAMPLE.csv)The MIDDEN TAXA PER SAMPLE table lists the plant macrofossil taxa identified in each midden sample by their assigned variable numbers (VARNUMs).  The MCOUNT field lists the symbols or numbers used in the source reference to represent macrofossil relative abundance or counts.  The table's NOTES field records discrepancies between taxon lists from different reference sources and indicates when a taxon was reported as an older or younger contaminant in a midden sample. LINKED TABLE 6: CODE TRANSLATION(Filenames: Linked_Table_6_CODE_TRANSLATION.xlsx, Linked_Table_6_CODE_TRANSLATION.csv)The CODE TRANSLATION table describes the different schemes used in each midden source publication to represent the relative abundance or counts of plant macrofossil taxa identified in the midden samples.  To facilitate comparison among midden samples, the original counting schemes were converted to a standardized 0-1-2 relative-abundance scale following rules modified from Strickland and others (2001).LINKED TABLE 7: MCOUNT TRANSLATION (Filenames: Linked_Table_7_MCOUNT_TRANSLATION.xlsx, Linked_Table_7_MCOUNT_TRANSLATION.csv)The MCOUNT TRANSLATION table lists the standardized macrofossil-relative-abundance 0-1-2 codes created for each macrofossil taxon MCOUNT value listed in the MIDDEN TAXA PER SAMPLE table (Linked Table 5).  The 0-1-2 codes were generated for each MCOUNT in the MIDDEN TAXA PER SAMPLE table according to the parameters defined for each midden source reference in the EXPLANATION and 0_1_2_CODE fields of the CODE TRANSLATION table (Linked Table 6).LINKED TABLE 8: CLIMATE DATA(Filenames: Linked_Table_8_CLIMATE_DATA.xlsx, Linked_Table_8_CLIMATE_DATA.csv)The CLIMATE DATA table lists the climate and bioclimate variables calculated for midden sample sites with best or published location data [i.e., BEST_OR_PUB_LATDECDEGCON, BEST_OR_PUB_LONGDECDEGCON, BEST_OR_ELEV(M)1].  CRU CL 2.0 (1961-1990 30-year mean) climate data (New and others, 2002) and World WeatherDisc (1951-1980) absolute minimum and maximum temperature (WeatherDisc Associates, 1989) were interpolated to each midden-sample site using lapse-rate adjusted bilinear interpolation (Thompson and others, 1999).  The monthly climate data were interpolated to daily data using a mean-preserving interpolation (Epstein, 1991; Bartlein and Shafer, 2019).  Bioclimatic variables were calculated using SPLASH (Davis and others, 2017, https://bitbucket.org/labprentice/splash/src/master/).  Snowfall snow water equivalent was calculated using equations from Tarboton and Luce (1996), assuming that all precipitation falls as snow at temperatures less than or equal to -1.0 degrees Celsius and no precipitation falls as snow at temperatures greater than or equal to 4.0 degrees Celsius.  Note that the climate and bioclimate data should be considered estimates of the conditions that would occur in unprotected, open areas near the packrat midden sites.LINKED TABLE 9: ECOREGION(Filenames: Linked_Table_9_ECOREGION.xlsx, Linked_Table_9_ECOREGION.csv)The ECOREGION table lists the World Wildlife Fund (WWF) major habitat types (MHTs) and ecoregions, which we refer to as Level II and Level III categories (Ricketts and others, 1999), for each midden-sample site location.  A value of "99999" indicates that a WWF ecoregion could not be determined for a midden-sample site (e.g., if location data for the midden-sample site were not available).LINKED TABLE 10: PLANT FUNCTIONAL TYPE(Filenames: Linked_Table_10_PLANT_FUNCTIONAL_TYPE.xlsx, Linked_Table_10_PLANT_FUNCTIONAL_TYPE.csv)The PLANT FUNCTIONAL TYPE table assigns each plant macrofossil taxon in the MIDDEN TAXA table (Linked Table 4) to one or more of 24 possible plant functional type (PFT) categories.  The PFT categories generally follow those of Thompson and Anderson (2000) and assignment of taxa to individual PFTs was based on descriptions of the taxa found in North American floras.UNLINKED DATA TABLES 1-4UNLINKED TABLE 1: SYNONYMS(Filenames: Unlinked_Table_1_SYNONYMS.xlsx, Unlinked_Table_1_SYNONYMS.csv)The SYNONYMS table provides the names of the plant macrofossil taxa listed in the MIDDEN TAXA table (Linked Table 4) which are synonymous with each other.  A macrofossil taxon may be represented in the midden database under as many as 8 synonymous names.  The SYNONYM table also provides the currently accepted taxon name.UNLINKED TABLE Table 2: MIDDEN RELATED PUBLICATIONS WITH NO SIGNIFICANT DATA(Filenames: Unlinked_Table_2_MIDDEN_RELATED_PUBLICATIONS_WITH_NO_SIGNIFICANT_DATA.xlsx, Unlinked_Table_2_MIDDEN_RELATED_PUBLICATIONS_WITH_NO_SIGNIFICANT_DATA.csv)The MIDDEN RELATED PUBLICATIONS WITH NO SIGNIFICANT DATA table lists publications that were consulted in the development of the midden database, but which did not contain enough significant midden data for inclusion in the database.UNLINKED TABLE 3: MIDDEN RELATED ABSTRACTS WITH NO SIGNIFICANT DATA (Filenames: Unlinked_Table_3_MIDDEN_RELATED_ABSTRACTS_WITH_NO_SIGNIFICANT_DATA.xlsx, Unlinked_Table_3_MIDDEN_RELATED_ABSTRACTS_WITH_NO_SIGNIFICANT_DATA.csv)The MIDDEN RELATED ABSTRACTS WITH NO SIGNIFICANT DATA table lists abstracts from conference proceedings that were consulted in the development of the midden database, but which did not contain enough significant midden data for inclusion in the database.UNLINKED TABLE 4: MIDDEN PUBLICATIONS OUTSIDE NORTH AMERICA (Filenames: Unlinked_Table_4_MIDDEN_PUBLICATIONS_OUTSIDE_NORTH_AMERICA.xlsx, Unlinked_Table_4_MIDDEN_PUBLICATIONS_OUTSIDE_NORTH_AMERICA.csv)The MIDDEN PUBLICATIONS OUTSIDE NORTH AMERICA table lists miscellaneous publications describing midden studies for sites outside of North America.  Data from these publications were not included in the midden database. LOOKUP TABLES 1-6LOOKUP TABLE 1: USE STATUS CODE (Filenames: Lookup_Table_1_USE_STATUS_CODE.xlsx, Lookup_Table_1_USE_STATUS_CODE.csv)The USE STATUS CODE table defines the use status codes (-9, 1, 2, 3, 4) that describe the data available for each midden sample.LOOKUP TABLE 2: 0-1-2 CODE (Filenames: Lookup_Table_2_0_1_2_CODE.xlsx, Lookup_Table_2_0_1_2_CODE.csv)The 0-1-2 CODE table defines the codes (0, 1, 2, 7, 9) that describe the plant macrofossil taxon relative abundance in each midden sample.LOOKUP TABLE 3: RECOMMENDED AGE CODE (Filenames: Lookup_Table_3_RECOMMENDED_AGE_CODE.xlsx, Lookup_Table_3_RECOMMENDED_AGE_CODE.csv)The RECOMMENDED AGE CODE table defines the age codes used in the AGEC14 table (Linked Table 3) to indicate which age is considered the best one to represent the age of a midden sample or assemblage when multiple ages are reported.LOOKUP TABLE 4: TAXON LIST CODE(Filenames: Lookup_Table_4_TAXON_LIST_CODE.xlsx, Lookup_Table_4_TAXON_LIST_CODE.csv)The TAXON LIST CODE table defines the taxon list codes used in the MIDDEN SAMPLE table (Linked Table 2) that indicate whether the macrofossil taxon list is complete, partial, published, or unpublished.LOOKUP TABLE 5: ECOREGION CODE (Filenames: Lookup_Table_5_ECOREGION_CODE.xlsx, Lookup_Table_5_ECOREGION_CODE.csv)The ECOREGION CODE table defines the abbreviations used in the ECOREGION table (Linked Table 9) for the WWF Level II MHTs and Level III ecoregions.LOOKUP TABLE 6: PLANT FUNCTIONAL TYPE CODE (Filenames: Lookup_Table_6_PLANT_FUNCTIONAL_TYPE_CODE.xlsx, Lookup_Table_6_PLANT_FUNCTIONAL_TYPE_CODE.csv)The PLANT FUNCTIONAL TYPE CODE table defines the PFT codes that are used in the PLANT FUNCTIONAL TYPE table (Linked Table 10) to represent the 24 PFT categories.----------ACKNOWLEDGEMENTS----------Development of this database has been supported by the
