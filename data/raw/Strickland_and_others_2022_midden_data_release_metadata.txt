  Description:
    Abstract: This data release contains the data tables for the USGS North American Packrat Midden Database (version 5.0).  This version of the Midden Database contains data for 3,331 packrat midden samples obtained from published sources (journal articles, book chapters, theses, dissertations, government and private industry reports, conference proceedings) as well as unpublished data contributed by researchers.  Compared to the previous version of the Midden Database (i.e., ver. 4), this version of the database (ver. 5.0) has been expanded to include more precise midden-sample site location data, calibrated midden-sample age data, and plant functional type (PFT) assignments for the taxa in each midden sample.  In addition, World Wildlife Fund ecoregion and major habitat type (MHT) assignments (Ricketts and others, 1999, Terrestrial ecoregions of North America—A conservation assessment) and modern climate and bioclimate data (New and others, 2002; Davis and others, 2017) are provided for each midden-sample site location.
    Purpose: The USGS North American Packrat Midden Database, Version 5.0, provides researchers with access to standardized midden derived paleobotanical data useful for investigating late Quaternary changes in plant species distributions in response to climate and environmental change.

    Process_Step:
      Process_Description: The data in this data release were created following the methods described here and in Strickland and others (2001, https://doi.org/10.3133/ofr0122).  We collected midden-sample data, including sample site location information, midden-sample ages, plant macrofossil taxon lists, and relative-abundance data, from published sources (book chapters, journal articles, theses, dissertations, government and private industry reports, conference proceedings).  In addition, some unpublished data were contributed by individual researchers.  Relative-abundance data for taxa were converted to a standardized presence-absence scale.
      Process_Date: 2016
    Process_Step:
      Process_Description: We interpolated CRU CL 2.0 (1961-1990 30-year mean; New et al. 2002, data available at https://crudata.uea.ac.uk/cru/data/hrg/) mean monthly temperature (°C), precipitation (mm), possible sunshine (%), and mean diurnal temperature range (°C) data to each midden-sample site location (latitude and longitude) and elevation (m) using lapse-rate adjusted bilinear interpolation (Thompson et al. 1999). The same approach was used to interpolate World WeatherDisc absolute minimum and maximum temperature (1951-1980; WeatherDisc Associates 1989) data to the midden-sample site locations.  The interpolated monthly climate data were used to calculate a set of bioclimatic variables (Table 11) for each midden site location using SPLASH (Davis et al. 2017; SPLASH code is available from https://bitbucket.org/labprentice/splash/src/master/). Snowfall snow water equivalent (SWE) was calculated using a threshold air temperature of -1.0 °C at which all precipitation falls as snow and a threshold air temperature of 4.0 °C at which no precipitation falls as snow (Tarboton and Luce 1996). Actual evapotranspiration (AET) was calculated by SPLASH using a soil moisture capacity of 150 mm for all midden-sample site locations. The annual Priestley-Taylor coefficient (α) was calculated as AET/EET, an evaporation-ratio variable (AETPET) as AET/PET, and the annual moisture index, MI (also known as the Budyko aridity index) was calculated as ANNP/PET.  Climate data are in "Linked_Table_8_CLIMATE_DATA" and "Linked_Table_8_CLIMATE_DATA.csv".
      Process_Date: 2022
    Process_Step:
      Process_Description: Midden location data were evaluated for inaccuracies and "best location" data were defined (see "Linked_Table_2_MIDDEN_SAMPLE.xlsx" and "Linked_Table_2_MIDDEN_SAMPLE.csv").  Midden-sample radiocarbon dates were calibrated using CALIB (ver. 7.0.4 (http://calib.org) and reported as calendar year BP (before present; see "Linked_Table_3_AGEC14.xlsx" and "Linked_Table_3_AGEC14.csv").  Fossil plant taxa were assigned to plant functional types (PFTs; see "Linked_Table_10_PLANT_FUNCTIONAL_TYPE.xlsx" and "Linked_Table_10_PLANT_FUNCTIONAL_TYPE.csv").  Each midden-sample site was assigned its World Wildlife Fund ecoregion and major habitat type (Ricketts and others, 1999, Terrestrial ecoregions of North America—A conservation assessment; "Linked_Table_9_ECOREGION.xlsx" and "Linked_Table_9_ECOREGION.csv").
      Process_Date: 2021
